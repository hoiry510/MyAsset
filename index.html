3대 가족 연금 설계

사람마다 현재 자산과 연도별 수입·보너스를 넣으면 부부 월 목표, 부모님 월 목표 달성 여부와 증여세를 바로 다시 계산합니다. 금액은 모두 만원, 현재 물가 기준입니다.

처음 들어 있는 값은 예시입니다. 실제 금액으로 바꿔 쓰세요. 입력한 내용은 이 브라우저에 자동 저장됩니다. 다른 기기로 옮기거나 백업하려면 「데이터 내보내기」로 받은 파일을 「데이터 불러오기」로 여세요. 세법·연금법 수치는 2026년 시행 기준이며, 실행 전 세무사·재무설계사와 확인하세요.

      사람별 연도별 수입 · 보너스

        계산 방식과 한계

        1. 모든 금액은 현재가치(실질)이며, 세금·건강보험료·수수료는 빼지 않았습니다. 「미래 금액」 보기는 물가상승률을 곱해 보여 줍니다.
        2. 필요 추가 저축은 은퇴 전까지 매달 금융자산에 더 넣을 금액을 이분법으로 찾은 값입니다.
        3. 증여세는 받는 사람·공제 그룹별 10년 합산으로 계산한 개략치입니다. 실제 신고는 증여자별 합산 규정이 달라 세무사 확인이 필요합니다.
        4. 공공데이터포털 국민연금공단 API는 사용 승인을 받지 못해(HTTP 403) 통계 대신 사용자가 넣은 예상액을 씁니다.
        투자 포트폴리오

        계좌별 수익률과 연령별 자산배분

        계좌마다 보유 종목·수량·매입가·현재가를 넣으면 수익률을 계산하고, 가족 구성원별 권장 배분과 비교해 리밸런싱 금액을 알려 줍니다. 계좌를 자산 행과 연결하면 평가액이 연금 시뮬레이션에 자동 반영됩니다.

        종목 사전과 가격 안내. 종목코드(예: 360750, VOO)나 이름을 입력하면 파일에 들어 있는 사전에서 종목명·자산군·통화를 자동으로 채웁니다. 아래 「시세 자동 조회」에 무료 API 키를 한 번 넣어 두면 인터넷이 연결됐을 때 현재가와 환율을 자동으로 채우고, 사전에 없는 종목도 코드만으로 이름을 찾아 줍니다. 오프라인에서는 현재가를 직접 넣으면 됩니다. 예시 종목의 가격은 실제 시세가 아닙니다. 이 화면은 투자 권유가 아니며, 투자 판단과 책임은 본인에게 있습니다.

        부동산 · 예금 · 금 · 가상자산

        증권 계좌 밖의 자산을 넣으면 매입가 대비 손익, 연평균 상승률, 대출을 뺀 순자산을 계산합니다. 「연금 시뮬레이션 자산과 연결」을 켜면 현재 시세가 자산 탭 금액에 반영되고, 연결하지 않은 자산은 대시보드에만 더해집니다. 금액 단위는 만원입니다. 시세는 KB부동산·국토교통부 실거래가·한국거래소 금시세 등으로 확인해 넣으세요.

        자산배분

        연령별 권장 배분과 현재 배분

        중립형 주식 비중은 110 − 나이(은퇴자는 100 − 나이)로 두고, 안정형은 15%p 낮게, 적극형은 15%p 높게 잡아 20~90% 안에서 정합니다. 타깃데이트펀드(TDF)의 글라이드패스처럼 나이가 들수록 주식을 줄이는 방식입니다. 주식은 국내·해외로 나누고, 금 5%와 현금성 5~10%를 두며 나머지는 채권입니다. 아래 매크로 신호에 따른 전술 조정(자산군별 최대 ±5%p)이 함께 반영됩니다.

          자주 묻는 질문

          휴대폰에서 고친 내용이 PC에 안 보여요.

          HTML 파일은 기기마다 따로 저장됩니다. 한쪽에서 「데이터 내보내기」 → 다른 쪽에서 「데이터 불러오기」를 하거나, 여러 기기에서 함께 쓰려면 공유 링크를 쓰세요.

          현재가가 어제 값이에요.

          국내 시세는 공공데이터 특성상 전 영업일 종가입니다. 장중 가격이 필요하면 현재가 칸에 직접 넣으면 됩니다(다음 자동 갱신 때 다시 종가로 바뀝니다).

          계좌 평가액을 고쳤는데 자산 탭 금액이 안 바뀌어요.

          계좌 설정의 「연결할 자산 행」을 고르고 「평가액을 자산 금액에 자동 반영」을 켜야 합니다. 연결된 자산 행은 자산 탭에서 직접 고칠 수 없습니다.

          대시보드 총자산이 생각보다 커요.

          같은 자산을 자산 탭과 포트폴리오 탭에 따로 적고 연결하지 않으면 두 번 더해집니다. 포트폴리오 쪽 항목을 자산 행과 연결하거나 한쪽을 지우세요. 「표로 보기」 아래에 연결 안 된 항목 이름이 나옵니다.

          목표 달성에 필요한 추가 저축이 「불가」로 나와요.

          이미 은퇴했거나 은퇴가 올해라 더 저축할 기간이 없는 경우입니다. 목표 생활비, 은퇴 나이, 주택연금 사용 여부를 조정해 보세요.
